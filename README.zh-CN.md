# COR3 Helper

一款 Chrome 扩展，通过监控市场、远征、每日行动并提供计时器提醒来增强 [cor3.gg](https://cor3.gg) 的使用体验——全部集成在紧凑的弹出窗口界面中。

## 功能特性

- **主题支持** — 多种配色主题以匹配你的偏好，其中包括与游戏原生界面配色一致的「Original」主题
- **弹出窗口 / 面板支持** — 可按你的偏好将界面导出为弹出窗口或侧边面板
- **刷新系统** — 既可通过「refresh all」按钮刷新，也可对每个区块单独点击「refresh」，从而更新界面上对应的数据
- **置顶计时器** — 除佣兵的「RESTING」计时器外，所有计时器都可以置顶到界面顶部以便跟踪
- **任务自动刷新** — 如果置顶任务计时器旁的「auto-refresh」复选框已启用，任务倒计时归零时会自动刷新。通过更早触发任务并留出足够的完成时间，让用户每天能接到更多任务
- **自动解密破解** — 启用后自动完成解密破解。只需打开开关，其余交由扩展处理
- **自动冰墙(ICE)破解** — 自动完成冰墙(ICE)破解小游戏。识别三角形图案并按正确顺序点击，从而完成谜题
- **自动简易解密破解** — 自动完成简易解密破解小游戏。点击解密按钮并监控进度直至完成
- **防挂机点击器** — 每 3 分钟在桌面外壳上模拟一次点击，自动避免防挂机锁屏出现。任何自动化功能启动时（自动任务求解器、自动高价出售、自动每日破解、破解求解器等）都会在内部自动启用
- **自动每日破解** — 全自动的每日行动求解器。打开每日行动标签页、启动任务、识别谜题类型（System Log Integrity 或 Signal Hack）、端到端完成、关闭窗口，并在完成后自动关闭开关。包含重试逻辑（最多 3 次尝试），重试之间会自动清理窗口
- **自动任务求解器** — 自动化市场任务求解器，支持 9 种任务类型：File Decryption、IP Injection、Data Download、Log Deletion、Log Download、Decrypt & Extract、File Elimination、Data Upload 和 IP Cleanup。提供标签式界面，展示 HOME、D4RK、SOYUZ 与 USOL 的市场任务，含按类型勾选框、开始/停止按钮，以及带 Jobs 与 Logs 标签的调试控制台。任务按服务器优先级（最远优先）与任务类型优先级排序，自动处理端点设置（不可达时进行穿透破解）、服务器登录（无有效权限时进行破解）、类型专属操作，以及任务完成与奖励跟踪。每个任务执行前检查服务器维护状态，跳过正处于维护中的服务器上的任务。包含动态装备栏管理——每个任务前自动装备正确的破解/解密软件，并在算力/软件报错时通过更换装备栏重试
- **自动高价出售** — 自动化高价文件/日志扫描与出售器。扫描所有可到达服务器上的高价文件与日志，下载它们，并出售给出价最高的市场。扫描前会按服务器类型自动装备最优的 SEARCH 与 HACK 软件。具备带实时进度日志的调试控制台、服务器/下载结果界面，以及含按服务器勾选与批量「Force selected!」的 Maintenance 标签（用于一次性触发多台服务器，按由远及近的顺序）
- **自动忽略失败任务** — 开关启用后，在每次求解器运行结束后自动忽略失败与异常任务，保持任务队列整洁
- **自动完成全部任务** — 后台调度，在重置后出现新任务时自动启动自动任务求解器。使用 chrome.alarms 在任务重置时间点调度运行，并带重试逻辑。即使弹出窗口关闭也能工作。具备服务器维护感知：跳过正处于维护中的服务器上的任务，并在任务重置时间与维护结束时间中较早的那个时间点安排重试。
- **市场穿透寻路** — 当市场服务器（D4RK、SOYUZ、USOL）或 USOL 佣兵端点不可达（no-path-to-server）时，动态获取实时网络地图，通过 DFS 找出所有路径，过滤掉被维护阻断的路线，并逐个走过中间服务器（设置端点 + 破解）后再重试目标。若某条路径中途失败，则退回到备用路径。
- **每日行动** — 到下一次每日行动任务的倒计时，含连续完成加成、难度与领取状态
- **市场监控** — 查看 Market-1 (HOME)、Market-2 (D4RK)、Market-3 (SOYUZ) 与 Market-4 (USOL) 的统计数据、任务重置计时器、物品列表（含用于查看物品详情的 INFO 弹窗）以及任务列表（含 Category/Server/Reward 列）
- **装备栏查看器** — 查看并管理已装备的硬件（CPU/GPU/RAM/PSU）与已安装的软件。游戏风格卡片式界面，含硬件规格、软件算力比、带启动状态的资源供需总览、硬件的 CHANGE/INFO 按钮，以及软件的排序/搜索/装备/卸下
- **进行中远征跟踪** — 查看进行中的远征，含剩余计时器、花费、风险、保险与佣兵信息
- **远征决策** — 查看待处理的决策，并通过点击（带分数计算）进行响应
- **自动选择决策** — 在截止时间前 1 分钟按评分自动选择决策。可配置战利品/风险修正值来改变评分方式。
- **物品栏查看器** — 按稀有度（最稀有在前）再按价格浏览你的藏匿点，含物品/仓储详情、总价值与最后更新时间戳
- **佣兵（多市场）** — 以可展开行加阵营图标查看 CORE 与 USOL 市场的佣兵。每张佣兵卡片显示呼号、等级、状态、专精、特质、任务次数、花费、休息计时器、风险、存活失败概率与死亡概率。精英佣兵以粗体「ELITE」徽章置顶显示。
- **自动派遣佣兵** — 启用「auto send」开关并选定一名佣兵，在当前远征结束后立即派遣。它会自动领取上一个奖励容器。在 CORE 与 USOL 市场均可用，且远征配置会感知市场。
- **自动选择佣兵** — 启用「auto choose」开关后，扩展会按各佣兵的花费与风险值在所有市场中挑选最优佣兵。
- **优先自动选择 USOL** — 启用后，在自动选择过程中 USOL 佣兵优先于 CORE 佣兵，会在考虑 CORE 之前先挑选最便宜的 USOL 佣兵。
- **忽略精英佣兵** — 启用后，精英佣兵将被排除在自动选择之外。
- **应用佣兵花费限制** — 启用后，花费高于所配置「Maximum merc cost limit」的佣兵会被排除在自动选择之外。默认上限为 15,000。
- **淘汰老兵** — 启用后，会为老兵佣兵远征覆盖战利品/风险修正值为 loot=1、risk=10，使决策偏向高风险选项，从而提高淘汰掉老兵佣兵的几率。位于 Decisions（决策）区块。
- **自动出售最便宜物品** — 启用「auto sell」开关后，当物品栏空间不足以拾取远征容器中的物品时，扩展会自动出售物品栏中最便宜的两件物品。
- **已归档远征** — 查看过往远征，含结果、花费、风险、地点、战利品容器详情与物品图片。启动时自动加载
- **多警报系统** — 可为任意计时器（每日行动、市场任务重置、远征）创建多个可配置警报。每个警报有独立的阈值、音量、连续模式与开关
- **移动通知** — 可将游戏内通知浮窗与历史面板从屏幕右侧移至左侧
- **秘密链接/服务器查找器** — 扫描网络地图上所有已知服务器 IP，以发现隐藏的连接与服务器。对每个已知 IP 发送 `connect.ip`，然后对比前后的地图数据。使用开关（扫描结束后自动关闭），进度与结果显示在日志框中。会报告发现的新连接与新服务器
- **仅助手模式** — 开关启用后隐藏所有自动化功能，将扩展转换为纯信息/助手工具
- **自动更新市场** — 开关启用后，在 WebSocket 事件到达时自动刷新市场数据
- **版本跟踪** — 显示扩展、web、系统与补丁版本
- **检查更新** — 将你已安装的扩展、web 与系统版本与 GitHub 上的最新版本进行对比。它会告知用户是否需要更新扩展，或 web/系统版本是否与已存储的版本不同。
- **缓存优先设计** — 打开弹出窗口时数据即时从缓存加载。使用「Refresh All」按钮或各区块的刷新按钮来获取最新数据
- **实时更新** — WebSocket 监听器会在数据到达时实时更新每日行动、市场、远征、决策、物品栏、佣兵、装备栏与已归档远征——即使弹出窗口在数据就绪之前就已打开
- **开发者工具 WS 检查器** — 内置 Chrome 开发者工具面板，用于实时 WebSocket 消息检查与多类别日志查看。功能包括：类别选择器（WS Messages、Auto Job Solver、Auto Valuable Seller、Error Logs、Page Console Logs、Extension Console Logs）、WS 消息的方向/事件/动作/服务器列过滤、日志类别的等级/消息列、格式下拉框（Raw / JSON-pretty / 带内联对象/数组预览的交互式树状视图）、消息详情内带高亮与导航的搜索（包括树状视图的遍历与自动展开）、将筛选后的数据导出为 JSON 或 Markdown 表格、分页日志显示（每页 1000 条）与区块选择器、基于 IndexedDB 的存储与 24 小时自动清理、按类别清空，以及可调整宽度的列/详情面板。包含一个离线弹出式日志查看器，可导入已导出的日志文件（JSON、MD、Discord 剪贴板格式）用于离线分析
- **轻量** — 仅拦截既有的 WebSocket 流量，并重新触发部分游戏本身已在发送的 API 调用

## 安装

### 方式 A：预构建发布版（推荐）

1. **下载** — 前往 [GitHub Releases](https://github.com/Femtoce11/cor3-helper/releases) 下载最新的 `dist.zip` 文件。

2. **解压** — 将 `dist.zip` 解压到电脑上的某个文件夹。

3. **打开 Chrome 扩展页面** — 在浏览器中访问 `chrome://extensions/`。

4. **启用开发者模式** — 打开右上角的 **Developer mode**（开发者模式）开关。

5. **加载扩展** — 点击 **Load unpacked**（加载已解压的扩展程序），并选择解压出的 `dist/` 文件夹（其中包含 `manifest.json`）。

6. **前往 cor3.gg** — 打开 [https://cor3.gg](https://cor3.gg) 并登录。扩展会自动开始拦截游戏数据。

7. **打开弹出窗口** — 点击浏览器工具栏中的 COR3 Helper 图标，查看你的仪表盘。

### 方式 B：从源码构建

1. **克隆** — 克隆仓库：
   ```
   git clone https://github.com/Femtoce11/cor3-helper.git
   ```

2. **安装依赖** — 在项目根目录运行：
   ```
   npm install
   ```

3. **构建** — 将扩展打包到 `dist/` 文件夹：
   ```
   npm run build
   ```
   开发时可用监听模式，在文件改动后重新构建：
   ```
   npm run watch
   ```

4. 按上面 **方式 A** 的第 3–7 步，在 Chrome 中加载 `dist/` 文件夹。

## 使用

- **页面加载时**，扩展会自动获取每日行动、市场数据、远征数据与佣兵数据，以填充缓存。
- **打开弹出窗口**即可看到缓存数据与「最后更新」时间戳，即时可用。
- **Refresh All**（全部刷新）按钮会按顺序刷新每日行动 → 市场 → 远征 -> 佣兵。
- **各区块的刷新**按钮让你可以单独刷新某一类数据。
- **置顶计时器**可让它们始终显示在弹出窗口顶部。
- **任务自动刷新**功能可用于：置顶计时器并勾选其旁的「Auto」复选框后，在需要时自动刷新任务。
- **自动解密破解** — 打开开关即可启用。只要出现解密破解就会自动完成。
- **自动冰墙(ICE)破解** — 打开开关即可启用。通过识别并点击三角形图案，自动完成冰墙(ICE)破解小游戏。
- **自动简易解密破解** — 打开开关即可启用。通过点击解密按钮并监控进度，自动完成简易解密破解小游戏。
- **自动每日破解** — 打开开关即可启用。它会打开每日行动、启动任务、自动完成谜题，并在完成后自行关闭。
- **自动任务求解器** — 打开开关以显示任务选择界面。在 HOME、D4RK、SOYUZ 与 USOL 市场标签中选择任务类型，然后点击 Start。调试控制台会显示实时任务进度与日志。启用「Auto Finish All Jobs」可实现全自动运行。
- **设置决策分数** 请点击编辑按钮。修改后点击保存按钮以保留更改。这样你就可以改变扩展在每个决策旁显示的默认评分。
- **启用自动选择决策**，扩展就会根据由默认/修改后的战利品/风险修正值计算出的评分自动选择最优决策。
- **启用自动派遣佣兵**，扩展就会在当前远征结束后自行派出选定的佣兵。
- **启用自动选择佣兵**，扩展就会按 CORE 与 USOL 市场中各佣兵的花费与风险值，决定下一次远征派遣哪名佣兵。仅在「auto-send」功能开启时生效。使用「Auto-choose USOL first」可优先选择 USOL 佣兵，使用「Ignore elite mercenary」可将精英佣兵排除在选择之外，配合已配置最高花费的「Apply merc cost limiter」可排除高价佣兵。
- **淘汰老兵** — 在 Decisions（决策）区块启用，可为老兵佣兵远征覆盖战利品/风险修正值（loot=1、risk=10），使自动选择偏向高风险选项。
- **秘密链接/服务器查找器** — 打开开关即可启用。它会通过逐个连接来扫描所有已知服务器 IP，然后对比前后的网络地图，以发现任何新的隐藏连接或服务器。扫描完成后开关会自动关闭。
- **警报（Alarms）** — 在 Alarms 区块点击 ➕ 创建新警报。选择计时器来源、设置阈值，并配置音量/连续蜂鸣。可随时开关、编辑或删除警报。
- **检查更新** — 点击弹出窗口底部的按钮，查看 GitHub 上是否有新版本的扩展。它也会显示 web/系统版本近期是否发生变化。
- **开发者工具 WS 检查器** — 打开 Chrome 开发者工具（F12），切换到「COR3 Helper」标签。使用类别选择器在 WS Messages、Auto Job Solver 日志、Auto Valuable Seller 日志、Error Logs、Page Console Logs 与 Extension Console Logs 之间切换。使用页面选择器浏览日志历史（每页 1000 条）。使用过滤输入框、格式下拉框、搜索栏与导出按钮来分析数据。切换 Live 模式可只查看自激活点起的新条目。点击 ⧉ 弹出按钮可在新窗口中打开离线日志查看器，导入此前导出的日志文件。
